# Velato - Pure Happiness in Every Scoop

## 1. Deskripsi Proyek
Velato adalah sebuah platform web e-commerce dan manajemen operasional toko gelato premium berbasis website. Aplikasi ini dirancang untuk memudahkan pelanggan dalam menjelajahi berbagai varian rasa gelato otentik berbahan organik, serta melakukan pemesanan secara online (Order Now). Di sisi lain, sistem ini juga menyediakan panel manajemen (admin) untuk mengelola data menu, transaksi, dan pengguna secara terintegrasi.

---

## 2. Fitur
Berdasarkan struktur arsitektur sistem, berikut adalah fitur-fitur utama Velato:

* Sisi Pelanggan (Customer):
    * Landing Page Interaktif: Menampilkan katalog produk, info varian rasa (Flavors), dan menu tentang kami (About).
    * Autentikasi Pengguna: Fitur pendaftaran akun (Register) dan masuk (Login) untuk pelanggan baru maupun lama.
    * Dashboard Customer: Halaman khusus pelanggan untuk memantau aktivitas akun.
    * Pemesanan & Pembayaran (Payment): Sistem checkout dan integrasi pembayaran untuk memesan gelato.
    * Manajemen Profil: Memperbarui data diri pelanggan.

* Sisi Admin (Back-Office):
    * Dashboard Admin: Panel ringkasan data operasional toko.
    * Manajemen Menu (Manage Menu): Fitur CRUD (Create, Read, Update, Delete) untuk menambah atau memperbarui varian rasa gelato.
    * Manajemen Transaksi (Transactions): Melacak dan memproses pesanan serta status pembayaran masuk.
    * Manajemen Pengguna (Users): Mengelola hak akses dan data pengguna yang terdaftar di sistem.

---

## 3. Tech Stack
Berdasarkan struktur direktori proyek (`VELATO-ICECREAM2`), teknologi yang digunakan meliputi:
* Framework Utama: Laravel (PHP) — terlihat dari penggunaan struktur arsitektur MVC, file `*.blade.php`, dan file routing `web.php` / `console.php`.
* Template Engine: Blade (Laravel built-in) untuk rendering tampilan dinamis.
* Frontend Styling & Scripting: CSS (`app.css`) dan JavaScript (`app.js`).
* Dependency Management: Composer (`composer.json` & `composer.lock`) untuk package PHP/Laravel.
* NPM (`package.json`) untuk package JavaScript/CSS.
* Environment & Konfigurasi: `.env` untuk konfigurasi database dan sistem kerja aplikasi.
